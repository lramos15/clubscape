# Agent Guide

Read [the project specification](prompt.md) before implementing game features.

Before installing tools or running builds and GPU tests, read the
[Sparky machine setup](docs/machines/sparky.md). It records installed versions,
tool locations, verified commands, and ARM64 graphics requirements.

That document is a dated host snapshot, not a universal requirement. Verify the
current host before applying machine-specific paths or package instructions, and
update the document after changing the development environment.

Toolchain and upstream RuneLite smoke tests do not prove ClubScape gameplay,
visual fidelity, or RuneLite compatibility. Keep those acceptance gates separate.
