Other sources and dependencies
------------------------------
Exact wiki revision URLs/hashes and contributor/copyright links are retained
in research/audio-source/references.json. Wiki prose and independent server
source snapshots are not published as game dialogue/code by this tool.
The isolated smelting reference is only a labeled candidate; no code is copied.

Gson, SLF4J, org.json, Guava, commons-compress and JNA remain original pinned
JARs with embedded upstream notices, under ignored .local/audio-import/tooling.
Additional artifact versions/licenses are retained via the checksum-locked
tools/cache-import/dependencies.json and THIRD_PARTY_NOTICES.txt.

The existing libsndfile1.2.2 and FLAC1.4.3 system libraries are used read-only,
not copied into this repository. Installed package notices remain unchanged.
Upstream licenses:
https://github.com/libsndfile/libsndfile/blob/1.2.2/COPYING
https://github.com/xiph/flac/blob/1.4.3/COPYING.Xiph
Neither codec's code license applies to the Jagex audio it packages.
