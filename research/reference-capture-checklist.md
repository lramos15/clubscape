blank captures, infer missing gameplay, or use the first ClubScape render as
the reference. No account credentials or personal account data belong in this
repository; use authorized synthetic/reference accounts and scrub secrets.

## Source journey observations

Use the frozen OSRS build-240/cache-2695 reference and record the actual client
build/cache, capture date and source paths. If a running reference has changed,
identify the difference; do not silently advance the frozen baseline.

Record a fresh normal account from initial appearance and experience selection
through the complete current **Learning the Ropes** tutorial. Preserve the
chosen experience option and any resulting Adventure Paths/arrival branch.
Observe initial stats, inventory/equipment, bank initialization, all tutorial
flags/stage guards, losses/deposits/replacements, departure possessions, Home
Teleport and actual arrival position/camera. Resolve the missing departure
text and older music/emote-guide conflicts identified in the mechanic notes.

Capture legitimate mining/banking/shopping/goblin combat, first Death's Office
visit and item recovery, and Cook's Assistant with real ingredient acquisition,
partial deliveries and rewards. Record exact tiles, floors, travel, object
variants and relevant authoritative outcomes.

## Visual/audio reference pack

Use stock visuals, Resizable - Classic, no HD/appearance-changing plugins.
Primary comparison is a 1920x1080 browser viewport. Record logical resolution,
device pixel ratio, UI scale, actual browser versions and a defined supported
resizing range. Pin camera position/pitch/yaw/zoom/projection, scene bounds,
draw distance, lighting, sampling, font metrics and animation timing.

Required matched states include title/login, registration composition,
loading/connecting, authentication feedback, reconnect/capability failures,
tutorial stages, Lumbridge arrival, tree and animated goblin, penguin adaptation,
HUD and every required interface. Web-only states need an explicitly approved
composition in the source visual language.

Record the actual music mode, track/SFX IDs, audio recordings, triggers,
timing/looping, transitions, volume/mute and browser gesture behavior. The
existing ID seeds are not a complete audio contract.

Before assessing ClubScape output, define numeric tolerances per comparison
case and narrow allowances for authorized adaptations/dynamic differences.
The complete pack needs one owner approval tied to its immutable manifest.
Later final visual/audio acceptance is a separate review against a built
candidate and its comparison evidence.

## Performance test environment

Provide a representative modern integrated-GPU test environment with exact GPU,
CPU, memory, OS/driver and desktop Chrome/Edge versions. Pin the benchmark
window and frame-time/stall acceptance contract before implementation. Run
actual tutorial/Lumbridge workloads with approved stock settings at 1920x1080
and measure rendered FPS, not a configured frame limit.

Sparky's NVIDIA GB10 supports local development, but its availability does not
establish a representative target contract or measured acceptance. Do not
classify the platform or infer performance equivalence from its model name.
Dedicated-GPU or software results must remain separately labeled.
