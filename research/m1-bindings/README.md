# M1 schema-2 source bindings

These records accompany real generated
[`GameContent`](../../content/m1/game-content.json.gz) and its strict Runtime
[`artifact`](../../content/m1/game-content.csc.gz). The v1 representation blockers
are replaced by typed mechanics, not ignored fields or a permissive parser.

`selection.json`, `wiki-sources.json`, `wiki-facts.json`, `runtime-source-facts.json`
and `code-sources.json` retain exact source identities and evidence. Original
cache placements, wiki location rows and inferred map-radius/landing candidates
remain distinct. The 146-definition original supplement and six original NPC
records retain hashes; neither is a substitute asset pack.

`world-bindings.json.gz` retains all151019 source object placements, all4837
definitions and all61 source scenes. `door-bindings.json` records the actual
typed transform groups, collision coverage and closed rat-pen cells.
`spawn-bindings.json.gz` preserves stationary access policies and the rejected
mobile source candidate without relocating it or clearing its clipping.
Source player arrivals are separate from NPC pins.

`graph-bindings.json` retains all73 tutorial edges,22 Cook edges and6 source
death edges. Every required tutorial/Cook edge has actual schema-2 bindings;
none remains disabled due to a v1 schema gap. `mechanics-bindings.json.gz` joins
all52 source rules and their exact arithmetic/source data to actual target IDs.
`policy-bindings.json` preserves all original assumptions and reconciliation
alternatives verbatim. `profile-v2.json` names provisional settings and bounded
ordinary-M1 versus rare-alternative scope without claiming approval.

`compiler-validation.json`, `schema-validation.json`, `check-result.json`,
`route-validation.json`, `state-oracle-validation.json`, `test-output.log` and
`repeatability.json` record qualified verification. The compiler is Runtime,
the artifact is version2, and the source JSON is actual schema2.
`unresolved-bindings.json` is the exact compiler-checked list of unresolved
paths with reasons/provenance. Unresolved values are **unavailable at runtime**,
not zeros, fixed timers, guaranteed drops or blanket source exclusions.

The source Wind Strike maximum-hit table is known, but its numeric JSON map
currently exposes an internally tagged shared-decoder issue. The schema check
reproduces that exact failure; only that field is withheld as unresolved pending
the Director's shared fix. It is not falsely described as an unknown source
formula or replaced by a fixed value.

Thirty source walking dependencies connect through declared open-state clipping;
all door states restore the exact source masks on close. These are topology and
post-event/state reference checks, **not execution** of unresolved projectile,
transit, departure or death policies. No renderer, raw asset, MIDI file, source
map pin or self-authored screenshot is treated as presentation/playback evidence.
Source snapshots, actual runtime execution, owner pack approval and final M1
acceptance remain separate.
