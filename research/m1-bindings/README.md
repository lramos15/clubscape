# M1 source bindings and unresolved representations

This is the binding companion to the **actual generated**
[`GameContent`](../../content/m1/game-content.json.gz), not a source-notes-only
deliverable or an accepted game.

## Canonical records

- `selection.json`: semantic-to-numeric IDs, source coordinate convention,
  explicit navigation/arrival candidates, corrected source roles and exclusions.
- `wiki-sources.json`, `wiki-facts.json`, `code-sources.json`: pinned public
  identity/position/constant evidence. Location rows and guide/map-radius anchors
  remain different evidence kinds; neither is a captured source session.
- `definitions.json.gz`: bounded additional original item definitions and
  existing decoded NPC records, with native payload/group/decoder hashes.
- `world-bindings.json.gz`: **all 151,019** individually identified object
  placements, 4,837 object/model/transform/morph records and 61 source scene links.
- `item-bindings.json`, `npc-bindings.json`, `interface-bindings.json`,
  `spawn-bindings.json.gz`: exact source variants, available source-worker asset
  references, missing dependencies and inference/rejection records.
- `travel-bindings.json`, `location-bindings.json`: real source transit object
  pairs and explicitly inferred adjacent/checkpoint coordinates.
- `mechanics-bindings.json.gz`: 52 source rules joined to real target IDs/spawns,
  exact integer success vectors, all source formulas, loot and death graph.
- `graph-bindings.json`: all 73 tutorial and 22 Cook edges, their actual runtime
  hook locations or explicit missing representations; full source death graph.
- `policy-bindings.json`: verbatim source initial/grant/departure/reward policies
  and all source assumptions. None is promoted to owner approval or observation.
- `contract-gaps.json`: precise missing shared representations and current
  fail-closed dispositions. The Director owns changes to shared contracts.
- `input-lock.json`, `structural-validation.json`, `route-validation.json`,
  `schema-validation.json`, `compiler-validation.json`, `test-output.log`:
  hash-bound inputs and qualified validation evidence.

## Reading the evidence

Original cache definition/placement identity is `verified_reference`. Published
wiki location rows are source references, **not observed runtime NPC spawning**.
Wander-area centers, inferred standing/landing tiles, the normal starting-house
candidate, translated 2020 instructor marker, older clipping algorithm
application, source uncertain mechanics and source variant choices remain
`inference`. There are no fixture sources or invented approvals in GameContent.

Do not solve the current compiler failure by clearing terrain or granting a
general NPC-walkability exception. It encounters the retained Death map pin
first; stationary source fishing NPCs are also in water, and one published
goblin point conflicts with reconstructed clipping. Resolve stationary NPC
semantics and actual spawn evidence separately from mobile-actor validation.
The four-plane source cells and original placements are preserved for that work.

Thirty walking dependency segments connect in the **separate, explicitly
door-open check map**. Runtime doors remain closed/unavailable, so this is not a
successful walk-through. Tutorial departure and Death's Office live instance
copy are explicitly unrepresented connections. No approved gameplay fence,
source camera, 3D rendering or actual audio playback is inferred from these files.

The 20 assumptions in `policy-bindings.json.decisions` include the source
fresh-container/25-bank-coin interpretation, tutorial XP boundary, lost-tool and
partial grant policies, departure normalization, cooking byproducts, timing,
loot supplement, price overstock and mill/death edge cases. Preserve their
approval and acceptance-impact records when integrating; do not normalize them
away to obtain a passing build or a seemingly complete journey.
