# First-slice interface evidence

Status: **not implemented; no approved reference pack**.

The required baseline layout is Resizable - Classic with stock visuals at
1920x1080; supported resizing bounds and capture settings must be established
in the reference pack. Other baseline layouts remain in full scope.

The pack and later interaction matrix must cover title/login, account
creation, loading/connecting, authentication feedback, reconnect/capability
errors, the HUD/minimap/chat/tabs/context menus, tutorial progressive unlocks,
inventory, equipment, skills, combat, bank, shop, dialogue, quest journal and
quest reward states. Include success, disabled, cancel and rejected actions
and their authoritative/persistence effects.

Registration and web-only loading/error compositions without a direct source
equivalent need explicit owner approval within the source visual language.
Do not replace them with generic website forms.

Section 30's unavailable-control adaptation preserves source placement,
provides clear feedback and retains genuinely locked/hidden tutorial states.
It cannot excuse a missing required control or tutorial/quest dependency.

Visual comparison uses actual source references and tolerances fixed before
evaluating ClubScape output. Whole unfinished panels may not be masked out.
Independent interaction evidence is required in addition to screenshots.
